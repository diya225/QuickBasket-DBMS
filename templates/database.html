KEY CONCURRENCY STATEMENT

Row lock before reserve

SELECT i.id, i.available_qty
FROM inventory AS i
JOIN bin_location AS b ON b.id = i.bin_id
WHERE b.store_id = :store_id
  AND i.product_id = :product_id
FOR UPDATE;

On MySQL/InnoDB, checkout locks the selected stock rows, checks quantity, reserves units, inserts the order and commits as one transaction.
